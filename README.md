# 句读（judou）

> 财报之不知，惑之不解。——开源的 AI 财报伴读器 + 标的编年史

**句读**（jù dòu），古人断句之法。财报是现代的"无句读之文"——亿级长数字、密集表格、散落各期的事件。句读做的事就是给它断句：

- **读**：像读书软件一样读财报 PDF 原文（巨潮一键下载 / 手动导入），巨长数字悬浮即得 `23.46 亿`
- **懂**：逐页速览、划词问答、多注家 AI 解读，回答必附页码
- **记**：一标的一档，全部财报与公告融合成编年时间轴，事件带利好/利空方向与原文引用，支撑你自己的决策

## 三条铁律

1. 用户始终在读原文——AI 是伴读不是替读
2. AI 只做有依据的解释——回答必须引用页码
3. 数字由程序计算，AI 只说人话
