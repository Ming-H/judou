# 术语点读 + 划词工具条 设计（注家系统·字词层）

> 2026-09-09 ｜ 对应 PRD F1.4（科目高亮）与 F6（注家系统）的字词层先行
> 范式参照：文言文阅读网站的「点词出注」与「划词查义」

## 定位

古籍阅读链条：断句 → 注（字词）→ 疏（段落）→ 译（白话）。句读已完成「断句」（数字句读），
本设计补「注」：财报术语点读。原则与铁律一脉相承——**基础知识程序供**（内置词典零 AI
成本、毫秒响应、绝不幻觉，与「数字程序算」同哲学），词典未收录才走 LLM 兜底（带上下文、
按 hash 缓存全站共享）。

## A. 术语词典与点读

- `src/core/glossary.json`：随代码走的静态词典（社区可 PR 扩充），种子约 100 条，
  七类：资产科目 / 负债科目 / 权益与损益 / 现金流 / 财务指标 / 报表与审计概念 / 公司事件与交易。
  每条 `{term, aliases[], plain, watch, category}`：
  - `plain`：一句话白话解释
  - `watch`：读财报时看这个数/概念关注什么（信息整理视角，非投资建议）
- `src/core/glossary.ts`：`matchTerms(spanText)`（span 粒度命中；**长词优先去重**——
  「归母净利润」命中时不再列「净利润」）、`lookupTerm(word)`（精确/别名，工具条解释用）
- 高亮：沿用 hl-num 的 span 模式加 `hl-term`，补齐 PRD F1.4 三模式规格：
  线条=科目浅实线底线（数字是虚线，可区分）、颜色=科目灰底（数字蓝底）、可全关
- 点读卡：点击术语 span → 悬浮卡（释义 + watch + 类别徽标 + `[✦ 问 AI 本页语境]`
  跳问答页签预填），标注「内置词典 · 程序匹配 · 非 AI 生成」；span 兼含数字时一卡分区

## C. 划词工具条 + LLM 解释兜底

- 划选任意文本 → 选区上方浮出工具条 `［123 换算］［📖 解释］［✦ 提问］`（统一样式；
  无数字时换算按钮隐藏）。**点击 span（数字/术语）=点读直出卡，划选=工具条**，两条入口并存
- 解释：`lookupTerm(选中文本)` 命中 → 直接出词典卡（零成本）；未收录 →
  `POST /api/ai/explain {docId, page, term}`：页 ±1 原文上下文解释该词在本页语境含义，
  无据则给通用义并明说；缓存键 `explain:{hash}:{term}:{model}`
- 提问：打开 AI 面板问答页签并引用划选文本（复用现有 quote 机制）
