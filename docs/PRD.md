> 版本：v1.0（最终版）｜ 2026-09-07 ｜ 配套：[BRD.md](BRD.md) ｜ [技术设计.md](技术设计.md)
> 功能编号体系 F1-F9；每项含用户故事、规格、验收标准（AC）。优先级：P0=MVP 必须，P1=云版必须，P2=增强。

## 1. 概述

**产品**：句读（judou）——开源 AI 财报伴读器 + 标的编年史。
**形态**（同一代码库）：云主站（注册使用，主打）／自部署（docker，数据全本地）／纯前端降级（免注册体验阅读）。
**铁律**（全功能约束，验收时逐条核对）：

1. 伴读不替读：任何 AI 输出同屏必须可达原文
2. 有据必引：AI 回答附页码/公告链接；无据答"不知道"
3. 数字程序算：换算/统计 100% 程序完成
4. 整理不荐股：影响方向 + 依据 + 用户改判；永不出现买卖建议措辞

**术语表**：文档（一份 PDF：财报/公告/其他）｜标的档案（一家公司的全部文档与衍生数据）｜事件（从公告/财报抽取的结构化事实）｜数字句读（长数字→万/亿可读形式）｜注家（同一段原文的不同解读视角模板）。

## 3. 功能规格

### F1 阅读器（P0）

**目标**：像读书软件一样读财报原文。

**规格**：
1. PDF 原版面渲染（财报表格重排必失真，故保留原版面，这是产品路线根基）
2. 连续阅读：上一页/下一页、页码跳转、键盘 ←/→；缩放（50%-200%）与适应宽度
3. **目录侧栏**：读取 PDF 书签（outline）；无书签时提供"财报标准章节速查"静态目录（重要提示/公司简介/管理层讨论/财报正文/附注）跳页
4. **语义叠加层**（在原版面上叠加非破坏性高亮，三种显示模式用户可切换）：
   - 线条模式（默认）：长数字加虚线下划线、科目名加浅底线
   - 颜色模式：数字蓝底、科目灰底
   - 全关：纯净原文
5. 批注/高亮/书签：落在页坐标，云端同步（自部署版存本地 JSON）
6. 阅读进度：每文档记住页码，文档库显示进度条
7. PWA：可安装到桌面/手机

**AC**：
- AC1.1 打开 200 页财报 3 秒内渲染首页
- AC1.2 目录点击跳页准确；键盘翻页无卡顿
- AC1.3 叠加层三模式切换即时生效，刷新后记住偏好
- AC1.4 任何缩放下文本可选中（文本层与渲染层像素对齐）

### F2 文档获取与文档库（P0）

**规格**：
1. **站内下载（巨潮）**：搜索公司名/代码 → 财报（年报/半年报/一季/三季）与公告列表 → 勾选入库；支持"一键拉取该公司全部历史财报"
2. **手动导入**：拖拽/选择上传任意 PDF（财报、公告、研报均可）
3. **文档库**：按公司自动归组；每条显示 公司/报告期/类型/大小/来源/阅读进度/预处理状态
4. 溯源：站内下载的文档记录巨潮公告 URL 与日期
5. 去重：按文件内容 hash，重复导入直接复用已有文档与预处理产物

**AC**：
- AC2.1 搜索"松发股份"返回其财报正本列表（摘要/英文版/更正被过滤）
- AC2.2 上传非 PDF 文件被拒绝并提示
- AC2.3 同一 PDF 二次导入不产生重复条目
- AC2.4 删除文档同时清理其文件与衍生数据

### F3 数字句读（P0，MVP 核心演示功能）

**规格**：
1. 悬浮卡：选中/点击任何数字 → 弹出卡片：
   - 第一层（P0，纯程序换算）：`2,345,678,901.23 元 → 23.46 亿 / 234,567.89 万`
   - 第二层（P1，接数字索引）：该数字被识别为已知科目时，追加本期 vs 上期同比
2. 换算规则：≥1 亿显示亿（保留 2 位）+ 万（千分位）；≥1 万显示万；<1 万原样
3. 全部由前端程序完成：零 LLM 成本、零延迟、零幻觉
4. 数字高亮见 F1 叠加层

**AC**：
- AC3.1 `2,345,678,901.23` → 卡片显示 `23.46 亿` 与 `234,567.89 万`
- AC3.2 `153,000,000` → `1.53 亿 / 15,300 万`
- AC3.3 `9,800` → 不触发换算卡片（低于阈值只原样显示）
- AC3.4 选中文本含多个数字时，卡片逐个列出

### F4 逐页速览（P1）

**规格**：每页 3-5 条要点，页边栏展示点击展开；预处理按页异步生成（进度条可见，单页失败可重试不阻塞整本）；产物按文档 hash 全站缓存。

**AC**：AC4.1 速览条目带页内小节定位；AC4.2 预处理中断后重试从断点续跑。

### F5 划词问答（P1）

**规格**：选中文本 → 提问；默认上下文 = 当前页 ±2 页原文；可扩为全文档检索式；回答格式 = 结论 + 依据引用（页码）+ 无据声明；防幻觉硬规则：上下文未命中即回答"原文中没有找到依据"。

**AC**：AC5.1 问"本期合同负债多少"能引用页码回答；AC5.2 问文档不存在的信息时明确回答无依据，不编造。

### F6 多层 AI 解读（注家系统，P1）

**规格**：一份原文，多套"注"，按需展开、互不干扰：

| 注 | 定位 | 输出 |
|---|---|---|
| 速览注 | 字词级 | F3/F4/F5 覆盖 |
| 导读注 | 篇章级 | "这份财报该重点读哪几节、为什么"（基于当期异常科目+近期公告事件，指向页码） |
| 框架注 | 方法论级 | 开放模板库：盈利质量核对/增长来源拆解/风险信号清单等 JSON 检查项模板，社区可贡献 |

**AC**：AC6.1 注可整体开关；AC6.2 框架注逐项给出 通过/不通过/文档未披露 三态+页码；AC6.3 所有注挂"AI 生成"标识。

### F7 读后综合与笔记（P1）

**规格**：读完点"综合保存"→ AI 综合卡（本期核心变化 3-5 条，每条带页码）与用户高亮/笔记并列存档；导出 Markdown（综合卡+笔记+引用）。

**AC**：AC7.1 综合卡每条可跳原文；AC7.2 导出文件可直接发知乎/雪球排版不乱。

### F8 标的档案与编年时间轴（P1，核心差异化）

**F8.1 标的档案页**：公司/代码/行业/最新报告期头部 + 三区块（编年时间轴/跨期科目追踪/文档列表）。

**F8.2 编年时间轴**：
```
2026-09-01 [订单·↑] 新接 10 亿美元 PCTC 订单 ←点击跳公告原文
2026-08-25 [财报·↑] 中报：营收 235 亿 +252%，合同负债 120.4 亿(环比+46%)
2026-07-29 [融资·→] 定增落地
2026-03-12 [减持·↓] 股东拟减持不超 2%
筛选：[订单][融资][筹码][业绩][风险]  方向：↑ ↓ →
```
- 事件抽取 = 规则层（标题关键词分类）+ LLM 层（正文结构化，schema 见技术设计 §6.2）
- **影响方向标注规范**：措辞"偏多 ↑/偏空 ↓/中性 →"；每条必附一句依据+源引用；**用户可一键改判且改判优先展示**；时间轴顶部固定免责声明（§5 文案）
- 每条事件强制带源（文档名+页码/公告链接）

**F8.3 跨期科目追踪**：科目近 N 期数值序列 + 环比/同比（程序计算）+ 一句 AI 注解带各期页码；**科目别名映射表**（处理"预收款项→合同负债"式重分类）用户可见可编辑，映射不静默合并。

**F8.4 实体追踪**：子公司/大客户/供应商/产品线/募投项目 ID 化；档案页查"该实体在各期文档的全部出现位置"（首期仅公司内实体，跨公司图谱为 V4）。

**F8.5 复盘卡（P2，远期）**：时间轴上每期财报为一个决策点——"回到当时，只有当时及之前的信息，你的判断是？"用户记录判断，后续披露自动对照。定位为读财报训练工具，非交易功能。

**AC**：
- AC8.1 拉取某标的全历史后，时间轴事件 ≥ 规则层覆盖（标题可分类的 100% 收录）
- AC8.2 每条事件点击可跳原文页码/公告
- AC8.3 合同负债 5 期追踪含各期页码引用；科目重分类处显示映射提示
- AC8.4 用户改判后该条展示用户方向并标注"你的判定"
- AC8.5 低置信度（<0.7）事件进入"待确认"折叠区而非主时间轴

### F9 账户 / 配额 / BYOK（P1，云版）

**规格**：
1. 分层（先给足价值再要注册）：匿名=纯前端阅读+数字换算（不耗服务端 LLM）；注册免费=月配额（30 份文档 AI 预处理 + 500 次问答 + 3 个标的档案）；BYOK=自填 key（GLM/OpenAI/Claude）配额无限
2. 认证：邮箱+密码、GitHub OAuth
3. BYOK 安全：key 加密存储（Supabase Vault）、服务端代理调用、永不下发浏览器
4. 存储配额：文档库默认 200MB/500 条（公共公告 hash 去重后实际占用极小）

**AC**：AC9.1 匿名用户完整走通 上传→阅读→换算；AC9.2 配额耗尽被温和限流并引导 BYOK；AC9.3 BYOK key 在任何前端响应中不可见。

## 4. 核心流程

**流程 1 新用户 5 分钟**：落地页（内置演示财报，免注册）→ 体验阅读/换算 → "导入你的财报" → 注册（云版）→ 拉取第一家公司 → 引导建档。

**流程 2 读一份财报**：文档库打开 → 目录跳"主要会计数据" → 逐页速览扫全篇 → 深读感兴趣页（数字悬浮+划词问答）→ 高亮笔记 → 综合保存入档。

**流程 3 建立跟踪**：搜标的 → 一键拉全历史 → 档案自动生成 → 看时间轴纵览 → 下季新财报入库 → 时间轴与科目序列自动延长。

**流程 4 决策支撑**：档案页 → 筛"订单+业绩"看利好链 → 筛"筹码"看减持解禁 → 科目时序看趋势 → 存疑事件跳原文核验 → 写"我的结论"笔记（产品到此为止，判断是用户的）。

## 5. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 首页 LCP < 2.5s；200 页 PDF 首页渲染 < 3s；数字换算 < 50ms（纯前端） |
| 可用性 | 自部署 `docker-compose up` 5 分钟内可用；无任何云依赖可完整运行 |
| **AIGC 标识** | 所有 AI 输出（速览/问答/注/事件/综合卡）统一挂显式"AI 生成"标识——依据《人工智能生成合成内容标识办法》 |
| **免责文案**（全站固定） | "本工具仅整理公开披露信息，不构成任何投资建议；数据以巨潮资讯网原文为准。"时间轴/档案页额外："影响方向为机器整理的提示，非投资建议；你的判定优先。" |
| 隐私 | 自部署数据全本地；云版 BYOK key 加密且仅服务端代理使用 |
| 可靠性 | 巨潮失败降级手动上传；预处理单页失败不阻塞；全站产物缓存命中即免算 |
| 兼容 | Chrome/Edge/Safari 最近两个大版本；移动端响应式（PWA） |
